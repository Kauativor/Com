FLOWBR - PROJETO GRADLE

Compilar no PC (Android Studio):
  File > Open > pasta FlowbrApp > Build > Build APK(s)

Compilar na nuvem (GitHub Actions):
  1. Crie um repositório privado no github.com.
  2. Envie todos os arquivos desta pasta (incluindo a pasta .github).
  3. Abra a aba Actions > Build APK > Run workflow.
  4. Quando terminar, baixe o arquivo flowbr-debug-apk em Artifacts.

Ícones: troque os ic_launcher.png em app/src/main/res/mipmap-*.
